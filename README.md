# Marzuk's Portfolio

My personal portfolio site. I'm Marzuk Almad, a Computer Science student at the University of Ghana, and this is where I keep my projects and ways to reach me.

Live site: https://o9scary.github.io/My-Portfolio/

## Built with

Plain HTML, CSS and JavaScript. No frameworks and no libraries, just a good excuse to get more comfortable with the basics.

## Run it locally

```
git clone https://github.com/O9SCARY/My-Portfolio.git
cd My-Portfolio
```

Then open `index.html` in your browser, or use the Live Server extension in VS Code.

## Structure

```
index.html   page markup
style.css    all styling
script.js    menu, scroll animations, counters, project filter
images/      photo and project screenshots
```
